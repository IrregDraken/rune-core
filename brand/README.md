# RUNE Brand System

This is the locked visual identity direction for RUNE.

## Core mark

The RUNE glyph is a geometric, interlocked symbol derived from the structure of the name rather than a generic fantasy rune. It is intended to work without the wordmark.

Primary uses:
- RUNE Shell / desktop island
- app icon
- favicon
- loading state
- notification identity
- device node identity
- future hardware surfaces

## Typography

**Primary:** Manrope  
Use for navigation, headings, conversational UI, labels and user-facing copy.

**Technical:** DM Mono  
Use for telemetry, system state, event IDs, modes, capabilities and machine-facing metadata.

The combination is deliberate:
- Manrope = human-facing RUNE
- DM Mono = machine nervous system

The repo references these fonts through the frontend stylesheet. For production/offline builds, self-host licensed font files instead of depending on Google Fonts.

## Palette

- Background: #080B0A
- Panel: #0E1311
- Primary green: #7DFFB2
- Text: #E8EEE9
- Muted: #7D8A82

Green is an accent and signal, not a blanket fill.

## Logo rules

- Keep the glyph readable at small sizes.
- Prefer the glyph alone for system surfaces.
- Use the wordmark when introducing RUNE.
- Do not stretch, rotate, bevel or add generic fantasy ornament.
- Do not substitute another rune font for the glyph.
- The mark should remain recognizable in monochrome.

## Product principle

The visual identity should communicate one thing:

**RUNE is persistent intelligence in motion.**

The interface can evolve, but the glyph, typography relationship and dark/green system remain the visual anchor.
